# GVCF Joint Genotyping & Filtering Pipeline

**English**  
This pipeline starts from sample-level GVCF files (generated by GATK HaplotypeCaller), performs **per-chromosome parallel joint genotyping** (CombineGVCFs + GenotypeGVCFs), merges the chromosome VCFs, and then applies a two-stage filtering strategy: **Hard Filtering** (using GATK VariantFiltration) followed by **Soft Filtering** (using VCFtools with mappability and population-genetic thresholds).

**中文**  
本流程从每个样本的 GVCF 文件开始，**按染色体并行**执行 GATK 的 CombineGVCFs 和 GenotypeGVCFs 进行联合分型，合并所有染色体 VCF 后，采用**两阶段过滤策略**：先进行**硬过滤 (Hard Filtering)**，再进行**软过滤 (Soft Filtering)**（结合可比对性区域和群体遗传学参数）。

## Overall Workflow / 整体流程

1. **01_generate_combine_per_chr.sh**  
   **English:** Reads the GVCF sample list and reference genome index, generates independent job scripts for each chromosome to run `CombineGVCFs` + `GenotypeGVCFs` in parallel, and finally creates a merge script (`merge_chr.sh`) to combine all chromosome VCFs into one.  
   **中文:** 读取 GVCF 样本列表和参考基因组索引，为每条染色体生成独立的作业脚本，并行执行 CombineGVCFs 和 GenotypeGVCFs，最后生成合并脚本将各染色体 VCF 合并为一个文件。

2. **QC assessment (optional but recommended) / QC 评估（可选但推荐）**  
   - `02_check.sh`: extracts the six hard-filtering metrics (QD, FS, SOR, MQ, MQRankSum, ReadPosRankSum) and summary statistics from the merged VCF.  
     从合并 VCF 中提取 6 个硬过滤指标（QD, FS, SOR, MQ, MQRankSum, ReadPosRankSum）及统计汇总。  
   - `03_plot_QC_metrics.R`: plots density distributions of these metrics with recommended thresholds.  
     绘制各指标密度分布图并标注推荐阈值。

3. **04_hard_filter.sh – Hard Filtering / 硬过滤**  
   **English:** Splits the merged VCF into SNPs and INDELs, applies GATK `VariantFiltration` to tag low-quality variants, and then extracts only `PASS` variants, producing the hard-filtered VCFs.  
   **中文:** 将合并 VCF 拆分为 SNP 和 INDEL，用 GATK VariantFiltration 标记低质量变异，然后提取 PASS 位点，得到硬过滤后的 VCF。

4. **05_genamp.sh – Mappability Analysis / 可比对性分析**  
   **English:** Uses `genmap` to build a mappability track for the reference genome, merges high‑mappability regions (score > 0.499) into a BED file for subsequent soft filtering.  
   **中文:** 使用 genmap 构建参考基因组的可比对性图谱，合并高可比对性区域（得分 > 0.499）为 BED 文件，供后续软过滤使用。

5. **06_filter.sh – Soft Filtering / 软过滤**  
   **English:** Based on the high‑mappability regions, applies four gradient filters using VCFtools (varying `--max-missing` and `--mac`) on the hard‑filtered VCF, while also controlling depth and retaining only biallelic sites.  
   **中文:** 在高可比对性区域基础上，用 VCFtools 对硬过滤后的 VCF 施加 4 组梯度过滤（变化 `--max-missing` 和 `--mac`），同时控制测序深度并保留双等位位点。

## Scripts Description / 脚本说明

### 01_generate_combine_per_chr.sh

**English:**  
Splits the GATK joint genotyping workflow by chromosome. It reads chromosome names from the reference `.fai` file, creates interval files (one per chromosome), and generates a separate qsub/bash script for each chromosome that runs CombineGVCFs and GenotypeGVCFs. Finally, it creates a merge script (`merge_chr.sh`) using GatherVcfs and a submission script (`submit_all.sh`) to launch all chromosome jobs.

**中文:**  
按染色体拆分 GATK 联合分型任务。从参考基因组 `.fai` 提取染色体列表，为每条染色体生成 interval 文件，并为每条染色体生成独立的作业脚本（执行 CombineGVCFs 和 GenotypeGVCFs）。最后生成合并脚本 (`merge_chr.sh`) 和一键提交脚本 (`submit_all.sh`)。

**Key variables to set inside the script / 需配置的变量**
- `workdir` – working directory / 工作目录
- `ref` – reference genome FASTA / 参考基因组 FASTA
- `args_file` – file listing all GVCFs (one per line, as required by `--arguments_file`) / GVCF 列表文件（每行一个）
- `GATK` – path to GATK executable / GATK 可执行文件路径
- `prefix` – output prefix / 输出文件前缀

**Outputs / 输出**
- Per‑chromosome interval files in `${workdir}/03_work/intervals/`  
  各染色体区间文件
- Per‑chromosome job scripts in `${workdir}/03_work/scripts/combine_chr_*.sh`  
  各染色体任务脚本
- Merge script `${workdir}/03_work/scripts/merge_chr.sh`  
  合并脚本
- Submission script `${workdir}/03_work/scripts/submit_all.sh`  
  一键提交脚本

### 02_check.sh & 03_plot_QC_metrics.R

**02_check.sh English:**  
Extracts from the merged VCF:
- GATK command‑line history (`gatk_history.txt`)
- Full bcftools stats report (`bcftools_stats.txt`)
- Sample list (`sample_list.txt`)
- Six hard‑filter metrics (QD, FS, SOR, MQ, MQRankSum, ReadPosRankSum) as a tab‑delimited file (`snp_QC_metrics.txt`)
- Summary statistics (mean, std, min, max) of each metric (`metrics_summary.txt`)

**02_check.sh 中文:**  
从合并 VCF 中提取：
- GATK 命令行历史
- bcftools 完整统计报告
- 样本列表
- 六个硬过滤指标（制表符分隔）
- 各指标汇总统计（均值、标准差、最小、最大）

**Variables to set / 需配置变量**
- `VCF` – input VCF file / 输入 VCF
- `OUTDIR` – output directory / 输出目录
- `zgrep`, `bcftools` – tool paths / 工具路径

**Usage / 用法**

    bash 02_check.sh

**03_plot_QC_metrics.R English:**  
Reads `snp_QC_metrics.txt` and produces a 2×3 density plot of the six QC metrics, with recommended human‑filtering thresholds marked as vertical lines (QD ≥ 2.0, FS ≤ 60.0, SOR ≤ 3.0, MQ ≥ 40.0, MQRankSum ≥ -12.5, ReadPosRankSum ≥ -8.0). Output is a PNG image.

**03_plot_QC_metrics.R 中文:**  
读取 `snp_QC_metrics.txt`，绘制 2×3 密度分布图，并标注人类推荐阈值（QD≥2.0, FS≤60.0, SOR≤3.0, MQ≥40.0, MQRankSum≥-12.5, ReadPosRankSum≥-8.0），输出 PNG 图片。

**Usage / 用法**

    Rscript 03_plot_QC_metrics.R [input_file] [output_png]

Defaults: `input_file = snp_QC_metrics.txt`, `output_png = QC_distributions.png`

### 04_hard_filter.sh – Hard Filtering / 硬过滤

**English:**  
Separates SNPs and INDELs from the merged VCF, applies GATK's VariantFiltration with stringent hard filters, and then extracts only PASS variants (using awk + bgzip). Finally indexes the filtered VCFs with tabix.

**中文:**  
将合并 VCF 拆分为 SNP 和 INDEL，用 GATK VariantFiltration 施加严格的硬过滤条件，然后提取 PASS 位点（awk + bgzip），最后用 tabix 建立索引。

**Filters applied / 过滤条件**
- **SNPs**: QD < 2.0, QUAL < 30, FS > 20, MQ < 20, MQRankSum < -0.5, ReadPosRankSum < -0.5
- **INDELs**: QD < 2.0, QUAL < 30, FS > 20, MQ < 20

**Variables to set / 需配置变量**
- `gatk`, `samtools`, `bgzip`, `tabix` – tool paths / 工具路径
- `refgenome` – reference FASTA / 参考基因组
- `vcf` – input VCF (the merged one) / 输入 VCF（合并后的）
- `out` – output directory / 输出目录
- `tmp` – temporary directory / 临时目录
- `species` – prefix for output files / 输出文件前缀

**Outputs / 输出**
- Raw split: `.snp.raw.vcf.gz` and `.indel.raw.vcf.gz`  
  原始拆分
- Filtered (with tags): `.snp.filtered.vcf.gz` and `.indel.filtered.vcf.gz`  
  带过滤标签的
- **Final hard‑filtered PASS‑only**: `.snp.final.hardfilter.vcf.gz` and `.indel.final.hardfilter.vcf.gz` (with `.tbi` indexes)  
  **最终硬过滤 PASS 位点**（含索引）

### 05_genamp.sh – Mappability Analysis / 可比对性分析

**English:**  
Builds a mappability track for the reference genome using genmap. It indexes the genome, computes mappability for k‑mer size 25 with up to 2 mismatches, keeps regions with mappability score > 0.499, merges overlapping regions, and compresses the output. The final merged high‑mappability BED file is `out_genmap/high_mappability.merge.bed`.

**中文:**  
使用 genmap 构建参考基因组的可比对性图谱。包括建立索引、计算 Kmer=25 且允许 2 个错配的可比对性、提取得分 > 0.499 的区域、合并重叠区域、压缩输出。最终合并的高可比对性 BED 文件为 `out_genmap/high_mappability.merge.bed`。

**Variables to set / 需配置变量**
- `genome` – reference genome FASTA / 参考基因组
- `Kmer` – k‑mer size (default 25) / Kmer 大小（默认 25）
- `Number_of_errors` – mismatches allowed (default 2) / 允许错配数（默认 2）
- `cpu` – number of threads / 线程数
- Paths to `genmap`, `bedtools`, `pigz` – 工具路径

**Outputs** (in `out_genmap/`) / 输出（位于 `out_genmap/`）
- `high_mappability.bed` (raw), `high_mappability.bed.gz` (compressed)  
  原始及压缩的高可比对性 BED
- `high_mappability.merge.bed` (merged) / 合并后的 BED
- Compressed `.genmap.bedgraph.gz` files / 压缩的 bedgraph 文件

### 06_filter.sh – Soft Filtering (Gradient Filtering) / 软过滤（梯度过滤）

**English:**  
This is the **soft filtering** step. On top of the hard‑filtered VCF, it applies four gradient filters using VCFtools, restricted to high‑mappability regions. All gradients share common parameters: `--minQ 30`, `--min-meanDP 5`, `--max-meanDP 150`, `--min-alleles 2`, `--max-alleles 2` (biallelic only). The four gradients vary in `--max-missing` and `--mac`:

**中文:**  
这是**软过滤**环节。在硬过滤基础上，用 VCFtools 在高可比对性区域内施加 4 组梯度过滤。所有梯度共用参数：`--minQ 30`、`--min-meanDP 5`、`--max-meanDP 150`、`--min-alleles 2`、`--max-alleles 2`（仅双等位）。四个梯度在 `--max-missing` 和 `--mac` 上变化：

| Gradient / 梯度 | `--max-missing` | `--mac` |
|----------------|----------------|---------|
| 1st / 第一组   | 0.9            | 1       |
| 2nd / 第二组   | 0.5            | 1       |
| 3rd / 第三组   | 0.2            | 1       |
| 4th / 第四组   | 0.9            | 0.5     |

**Variables to set / 需配置变量**
- `workdir` – base directory / 基础目录
- `INPUT_VCF` – input VCF (usually the hard‑filtered VCF) / 输入 VCF（通常为硬过滤后的）
- `INCLUDE_BED` – high‑mappability BED file (from `05_genamp.sh`) / 高可比对性 BED 文件
- `OUTDIR` – output directory / 输出目录
- `OUT_PREFIX` – prefix for output files / 输出前缀
- Paths to `vcftools`, `bgzip`, `tabix` – 工具路径

**Outputs / 输出**
- `${OUT_PREFIX}.first.vcf.gz`
- `${OUT_PREFIX}.second.vcf.gz`
- `${OUT_PREFIX}.third.vcf.gz`
- `${OUT_PREFIX}.fourth.vcf.gz`
- Corresponding `.tbi` indexes. / 对应的 `.tbi` 索引文件。

## Usage / 使用方法

1. **Configure** all paths and variables in each script according to your environment.  
   **配置**：根据您的环境修改每个脚本中的路径和变量。

2. **Prepare** a list of GVCF files (one per line) as required by GATK's `--arguments_file`.  
   **准备**：按 GATK 的 `--arguments_file` 要求，准备一个 GVCF 列表文件（每行一个）。

3. **Run** `01_generate_combine_per_chr.sh` to generate all per‑chromosome scripts.  
   **运行** `01_generate_combine_per_chr.sh` 生成所有染色体脚本。

4. **Submit** the chromosome jobs:  
   **提交**染色体任务：

        bash ${workdir}/03_work/scripts/submit_all.sh

   (or manually submit each `combine_chr_*.sh` with `qsub` or `bash`.)  
   （或手动逐个提交。）

5. **Merge** after all chromosome jobs finish:  
   **合并**（所有染色体任务完成后）：

        qsub ${workdir}/03_work/scripts/merge_chr.sh

6. **Extract QC metrics** (optional but recommended):  
   **提取 QC 指标**（可选但推荐）：

        bash 02_check.sh

7. **Generate QC plots**:  
   **生成 QC 图**：

        Rscript 03_plot_QC_metrics.R ./check_results/snp_QC_metrics.txt ./QC_distributions.png

8. **Apply hard filtering**:  
   **执行硬过滤**：

        bash 04_hard_filter.sh

9. **Build mappability track** (once per reference):  
   **构建可比对性图谱**（每个参考基因组只需一次）：

        bash 05_genamp.sh

10. **Apply soft filtering (gradient filters)**:  
    **执行软过滤（梯度过滤）**：

        bash 06_filter.sh

## Outputs / 输出文件

The main final outputs are:  
主要最终输出文件：

- **Hard‑filtered SNPs and INDELs** (PASS only) from `04_hard_filter.sh`.  
  **硬过滤后的 SNP 和 INDEL**（仅 PASS）来自 `04_hard_filter.sh`。
- **Four gradient‑filtered VCFs** from `06_filter.sh`, restricted to high‑mappability regions.  
  **四个梯度过滤后的 VCF** 来自 `06_filter.sh`，限制在高可比对性区域。
- **QC reports and plots** from `02_check.sh` and `03_plot_QC_metrics.R` for quality assessment.  
  **QC 报告和图片** 来自 `02_check.sh` 和 `03_plot_QC_metrics.R`，用于质量评估。

All intermediate files (per‑chromosome VCFs, filtered tagged VCFs) are kept for troubleshooting.  
所有中间文件（按染色体 VCF、带过滤标记的 VCF）均保留，以便排查问题。
